# LojDiceRoller

## What's This?

This is a Revolt bot centered around TTRPG functionality (e.g. rolling dice via formula) that's intended for use in a private Revolt server. Currently, the only feature is the ability to roll dice via a formula, such as "2d6" (which would roll two six-sided dice) or "3d10+2" (which would roll three ten-sided dice and add two to the total).

## Installation and Usage

First, ensure that your device has Node.js, NPM or Yarn (recommended, faster), and Git installed. Then, you can follow these steps:

1. Clone this repository: `git clone https://github.com/League-of-Jackasses/LoJDiceRoller.git`.
2. Install the dependencies by running `npm install` or `yarn install`.
3. Copy the `.env_CONFIGUREME` file to `.env` and configure it with your Revolt bot token as well as any other settings where the defaults are not satisfactory.
4. Run the bot using `npm start` or `yarn start`.
5. That's it! The bot should now be functional and ready for use in your Revolt server.
